# Cantinho do Maná

Cardápio digital com marmitas, porções, copos da felicidade e kits festa. Os botões abrem o WhatsApp com o item selecionado.

## Visualizar

Abra o arquivo `index.html` no navegador. As fotos estão incorporadas no HTML.

## Publicar com GitHub Pages

1. Coloque `index.html` e `README.md` na raiz do repositório.
2. No GitHub, acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`. Clique em **Save**.
5. Abra o endereço exibido em **Settings → Pages** após a publicação.
